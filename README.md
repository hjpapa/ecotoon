# 충주용산초경제툰

초등학교 1~6학년을 위한 경제·노동·금융 웹툰 사이트입니다. 학년마다 15편(영역별 5편), 이야기마다 8장면으로 총 90편·720장면을 제공합니다.

지우와 하린은 학년이 올라가며 외형과 말투가 자랍니다. 각 이야기에는 전용 삽화 8장면이 있습니다. 같은 대표 그림을 여러 이야기에 돌려 쓰지 않고, 사건에 따라 시선·손동작·자세·표정·구도가 달라집니다. 말풍선은 그림과 함께 표시되며 작은 화면에서도 읽을 수 있도록 높이가 늘어납니다. 두 친구의 좌우 자리가 바뀐 장면은 `reverseSpeakers`로 말풍선 방향을 맞춥니다. 장면 설명은 그림 위에 두어 얼굴을 가리지 않습니다.

모든 이야기는 생활 사건에서 시작해 서로 다른 생각, 선택, 결과로 이어집니다. 각 편에는 상황을 여는 소개와 8개의 행동 묘사, 장면마다 주고받는 두 말풍선이 있습니다. 저학년은 장터·집안일·소풍·저축 경험을, 중학년은 파티·지역 조사·학교 축제를, 고학년은 모의 장터·교류·창업 프로젝트를 중심으로 전개합니다. 학습 주제명과 이야기 제목을 함께 표시하며, 개념 정리는 이야기를 읽은 뒤 만납니다.

18편의 전개를 추가로 보강했습니다. 동전을 놓쳐 찾아보는 사건, 바퀴가 멈춰 소풍에 늦을 위기, 빌린 놀이 돈을 선물로 착각한 선택, 판매금과 임금을 혼동한 봉투, 실행하다 실패한 창업 시제품처럼 구체적인 문제를 해결하며 개념을 발견합니다. 결과가 아쉽거나 계획을 수정해야 하는 장면에서는 표정도 그 상황에 맞춥니다.

## 실행

빌드나 패키지 설치 없이 정적 웹 서버로 실행합니다.

```sh
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. 정적 호스팅에는 저장소 루트의 HTML·JS·CSS와 `assets/`를 함께 배포하세요. Vercel 설정은 `vercel.json`에 있습니다.

## 이야기와 게임

- `catalog.js`: 요청한 학년별 주제, 8장면 대사, 학습 원칙, 퀴즈, 생활 활동, 게임 데이터
- `app.js`: 학년·영역 필터, 웹툰 읽기, 활동 저장, 게임 열기, 학습 기록
- `games.js`: 금액 만들기, 짝 연결, 순서 잇기, 상황 분류, 예산 세우기, 가상 분산 실험
- `growth.css`: 이야기별 그림의 장면 분리, 만화 안의 말풍선, 모바일 게임 화면
- `assets/episodes/g1-01.webp`~`g6-15.webp`: 90편의 전용 삽화. 파일 하나마다 2열×4행의 8장면을 시간순으로 담습니다.
- `assets/growth-grade-1.png`~`growth-grade-6.png`: 학년별 캐릭터 원본 참고 그림. 웹툰 본문에는 사용하지 않습니다. 메인의 성장 소개에는 같은 그림의 WebP 파일을 사용합니다.
- `production/storyboards.json`: 90편의 장면별 행동·대사·감정·구도 제작 지시
- `production/generated/`: 생성 이미지의 크기·용량·SHA-256 기록
- `production/review.json`: 90편의 육안 검수, 말풍선 좌우 위치, 그림 수정 이력

본문은 각 편의 실제 이미지 크기에 맞춰 장면을 나눕니다. 표지는 그 이야기의 첫 장면이며, 8장면은 하나의 WebP 파일을 공유하므로 같은 이야기를 읽을 때 그림 파일을 여덟 번 받지 않습니다. 이미지에 `loading="lazy"`를 적용해 화면에 가까운 그림부터 읽습니다. 생성 도구의 원본 PNG는 클라우드의 `/workspace/generated_images/`에 보관하고 사이트에는 압축한 WebP를 배포합니다.

‘생활 속으로 한 걸음’에서 **활동 저장하고 읽기 완료**를 누르면 해당 이야기의 게임이 열립니다. 구술·그림 활동을 한 어린이도 완료할 수 있도록 기록 입력은 필수가 아닙니다. 게임을 끝내면 완료 여부와 최고 별 기록을 보관하며 다시 도전할 수 있습니다.

기록은 `localStorage`의 `ecotoon-progress-v3`에 저장됩니다. 이전 버전의 기록은 관련된 새 주제로 옮기고 기존 저장 키는 보존합니다. 기록은 같은 기기·브라우저·사이트 주소에서만 유지되며 다른 기기와 동기화되지 않습니다. 브라우저 저장을 사용할 수 없으면 현재 화면에서 읽기와 게임을 진행할 수 있습니다.

## 검증

Chromium 브라우저에서 90개 이야기의 8장면, 학년·영역 필터, 퀴즈, 게임 잠금·해제, 90개 게임의 완료, 새로고침 후 기록 유지, 이전 기록 이전을 확인했습니다. 320·390·1440px 화면에서 말풍선 경계와 8장면 이동을 확인했습니다.

이야기 개편 후에는 90개의 고유한 이야기 제목·상황 소개, 720개의 행동 묘사와 1,440개의 대사를 확인했습니다. 세 가지 화면 폭에서 전편의 두 말풍선이 겹치거나 잘리지 않는지 확인하고, 기존 기록과 게임 데이터 보존·게임 열기·장면 이동을 검증했습니다.

전용 삽화 개편 후 90편 모두 그림과 대사를 대조했습니다. 동전 개수, 저축 목표, 인물 가림, 모의 활동 장소 등 어긋난 장면을 수정했습니다. Chromium에서 90개 WebP의 해독, 720장면의 중복 여부와 분리 위치, 말풍선 방향을 확인했으며 누락 파일과 JavaScript 오류는 없었습니다. 첫 화면은 지연 로딩으로 90개 중 4개의 이야기 그림만 요청했습니다. 이야기 삽화 전체는 약 32.6MiB이며, 한 편의 8장면은 하나의 파일을 공유합니다.

이야기를 수정할 때는 장면 수와 게임의 해결 가능성을 함께 확인하세요. 금융·무역·계약·창업 활동은 놀이 돈과 가상 상황을 사용합니다.

새 삽화의 누락·파일 중복·장면 순서·실제 크기·체크섬·제작 지시와 대사 일치를 확인하려면 다음 명령을 실행합니다. Node.js의 기본 모듈만 사용합니다.

```sh
node scripts/verify-episodes.cjs
```
